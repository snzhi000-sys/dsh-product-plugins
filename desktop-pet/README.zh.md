# 桌面宠物

[English](README.md) | 中文

一个住在桌面透明窗口里的伙伴插件：内置角色库与角色选择器，角色会跟随鼠标、说话时张嘴、把文字念出来，并有自己的对话与情绪。

## 概述

**一个插件三件事**：角色库与立绘渲染、鼠标跟随与口型、朗读与语音对话。三者共用同一套角色配置与音频队列。

**核心能力**：

- **角色库**：内置 19 位伙伴、23 套造型，含 22 个 Live2D 模型版本与龙骨驱动的萌妹，每个角色自动使用自己的动画驱动；
- **跟随与互动**：视线与身体一起跟随鼠标，支持摸头、拖动与动作预览；
- **朗读**：每条回复可念、可划词念、可播报主对话，口型跟随音频；
- **独立对话**：桌宠有自己的模型配置、情绪与亲密度，与 Harness 主对话互不干扰。

**素材来源**：主推形象「萌妹」的素材由**苍月动漫**提供，我们在此基础上完成 Live2D／龙骨驱动、鼠标跟随、口型与语音链路；角色形象与模型的全部权利归素材方所有。其余内置 Live2D 模型取自第三方合集，来源与条款见 `assets/NOTICE.txt`，**模型文件随本插件与本仓库一起分发**，不在本仓库 MIT 许可的覆盖范围内。

## 使用

### 打开与切换角色

左侧栏打开**桌宠**面板，在可滚动的角色列表里浏览或按名称搜索，点任意一行即切换并保存。萌妹排在第一位、默认选中。

同一角色的不同服装合并为一个条目，例如 Mori 的 4 套、户山香澄的 2 套，在角色详情里切换；已保存但被移除的角色回退到萌妹。

### 显示设置

**每一项改动后立即保存，没有保存按钮**：

- **角色显示大小**：拖动滑杆时合并保存；
- **开启动画**：关闭后角色复位并静止；
- **保持在窗口上方**；
- **显示伙伴**：打开恢复桌宠窗口，关闭释放原生渲染窗口。

面板入口与「插件」并列，打开后以主面板替换对话区，没有需要关闭的弹窗；把侧栏切回工作区或切到插件即释放预览。

### 互动

**左键互动、右键菜单**：轻轻摸头、点击身体或拖动角色，动作、表情、视线与物理效果取决于模型本身。

设置里展开「动作调试」后，按住动作或表情按钮可在立绘与已显示的桌宠上同步预览；松开、取消、失焦、切换标签或关闭设置后恢复。实际显示且开启动画的桌宠空闲满 60 秒后，会随机执行一个可用肢体动作，尽量不连续重复；点击、菜单、拖拽、暂停或隐藏会打断。立绘不参与自动动作。

## 朗读与播报

### 每条回复的朗读按钮

**官方回复动作条里，与复制／分享同一排**。静息时是扬声器图标，按下即用桌宠的声音念这条回复。

朗读中按钮变成上下起伏的波形，此时再按就是**停止全部朗读**——这条回复、别的回复、划词朗读的那段，以及主对话的自动播报一起停。按钮描述的是「桌宠的嗓音」而不是它自己那次请求，所以只要已经有声音在放，按钮就始终可按，停永远优先于开始。

它能念本次运行之前的旧回复；**朗读不要求显示伙伴**：桌宠在屏幕上时由它出声并驱动口型，隐藏时由 Harness 窗口出声，隐藏不会中断正在念的内容。

### 划词朗读

**在对话面板里选中文字**，选区上方浮出「朗读」胶囊，点击即用桌宠的音色与队列播出来。

- **只念人话**：代码块、表格与 Markdown 修饰不念，未闭合的代码块更不会念；
- **不写气泡**：朗读内容不进入桌宠气泡，也不进入会话日志与模型请求；
- **超长不提供**：超过 5000 字的选区直接不提供；
- **与引用并排**：在文件浏览器里选中文字时，朗读动作投递进「@引用」气泡，两个按钮并排；
- **缺什么说清楚**：没有 TTS Key 或没有可播放窗口时，胶囊上直接写明原因。

### 播报主对话

**默认关闭，开关在对话标题栏右侧**：喇叭图标区分「声音开启／声音关闭」，伙伴页不重复这个开关。

- **只播报说给你听的部分**：主对话里大模型的正文会念出来，思考、工具调用、压缩与生成标题这类内部请求都排除；代码块、表格、Markdown 修饰与链接不读；
- **不写进桌宠气泡**：气泡只属于桌宠自己的对话，共用会把已经关掉的字幕又调回来；
- **开关同时是停止键**：关闭会立刻结束正在念的那一句，桌宠窗口隐藏时屏幕上只有这个开关；
- **子代理不播报**：避免把主线的汇报淹没；
- **需要 TTS**：用的是桌宠自己的音色与 Key，与桌宠私聊的自动朗读互不影响。

## 对话

### 私聊与录音

从桌宠菜单打开「聊天」，角色下方显示文本输入框；「关闭聊天」只收起输入框，不重置记录。它与设置 →「聊天记录」共用最近一次对话与有上限的上下文。

- **发送**：Enter 发送、Shift+Enter 换行，中文输入法组合期间不发送；
- **每次按下都有回应**：按钮不做禁用，按下即显示「发送中…」；确实忙时先向宿主核对并把原因写进气泡，发送请求有 30 秒上限；
- **录音**：录音结果可修改后显式发送，开始采集会停止朗读；麦克风只允许内嵌聊天页申请；
- **一轮一配置**：一轮回复固定使用开始时的配置，修改在下一轮生效。

### 情绪

**情绪是五个按顺序排列、以「我」书写的纯文本字段**：当前心情、态度方向、内心波澜、语气色彩、情绪基调。

- **Prompt 纪律**：禁止话题引导、条件式回复指令与虚构人设事实；
- **共用桌宠模型**：首轮先分析用户消息再回复，之后每次完成回复后分析双方最近八条消息，`emotionHistoryMessages` 可设为 1–100；
- **失败保留上次情绪**：缺失、重复、乱序或非第一人称字段会使更新失败，旧情绪不被覆盖；
- **可注入**：Prompt 里的 `{{情绪模拟}}`、`{{聊天记录}}`、`{{亲密情况}}` 在指定位置展开。

### Prompt 管理

分别编辑对话与情绪 Prompt。不含变量的自定义 Prompt 原样保留；与旧默认完全一致的 Prompt 自动升级。情绪文本与请求独立于聊天消息与 TTS，新对话清空情绪、重新打开会恢复。

### 亲密度

`intimacyLevels` 可编辑任意多个等级的名称、起始分数、结束分数与描述，区间从 0 开始连续排列、不允许重叠或遗漏。

每完成一轮非空用户／AI 回复加 1 分且只计一次；中断、失败、连接测试与情绪请求不计分。重新打开保留分数，新建对话清零但保留等级设置。

## 语音与口型

### 语音配置

「对话」与「声音」页配置桌宠自己的方舟地址、模型和独立的模型／TTS／ASR Key，**不继承 Harness 的模型设置**。

- **音色**：朗读需要 TTS Key 与音色 ID，支持已有克隆 speaker ID，不含音色训练；
- **保存并试听**：先保存当前表单再合成；
- **Key 语义**：留空保持原值，清空后自动保存即删除；GET 只返回是否配置；
- **流式合成**：按播放器消费进度只合成后面两三句，长回复不会撑爆缓冲。

### 口型驱动

**Live2D 与龙骨各有一套驱动**：

- **Live2D**：时间轴直接驱动 `ParamMouthOpenY` / `PARAM_MOUTH_OPEN_Y`，并使用设置里的口型配方权重；
- **龙骨**：手工制作的 a／o／i／m 四个口型，按拼音近似匹配，萌妹的 `i` 改用收窄的 `a` 以保证看得出来；
- **静音闭合**：静音时闭嘴，片段结束即释放；
- **近似口型**：两种驱动都不宣称音素级对齐。

### 只念人话

**先把文字转成「读法」再取元音**：阿拉伯数字按中文数字，拉丁字母按字母名，常见符号按读法转写，例如 `%` 读作百分号、`@` 读作艾特；书名号、引号、括号、逗号句号只当停顿。数字逐位读，数字内的分隔符按读法处理。

**字幕时间不可信时会重排**：语音服务对任何含数字或符号的片段返回固定 30 毫秒跨度，相信它会把整段读法塞进 30 毫秒、留下长段闭嘴。插件改按音频自身的有声片段重排，让嘴只在音频真的停顿时闭合；音频与负载一致的片段完全保留供应商原始时间。

## 数据与隐私

- **位置**：外观设置、对话、凭据索引与录音记录保存在 `DSH_HOME/state/dsh-desktop-pet`；
- **Key**：保存为权限 0600 的私有文件，不是加密存储；
- **不随包分发**：这些文件与请求记录不进入发行包；
- **本机访问**：Host 路由限制本机同源访问，并拒绝资源路径越界与符号链接逃逸。

## 素材与角色库

`assets/catalog.json` 管理稳定标识、名称、相对入口与预设互动配置，Host 直接从插件包读取模型与 Core；用户无需导入目录、选择驱动、绑定动作或填写路径。

**新增角色在开发时完成**：`scripts/prepare-builtin-assets.mjs` 只复制模型依赖与已确认的动画配置，不复制用户设置、凭据、模型库索引或含绝对路径的来源文件；扩展资源由 `scripts/additional-models.json` 固定来源并校验依赖哈希，`scripts/verify-additional-models.mjs` 在入库前用真实驱动播放全部声明动作。

## 驱动与构建

### DragonBones

萌妹由 `node scripts/prepare-dragonbones.mjs <原始导出目录>` 从三个原始文件准备：为物理约束加名称前缀、保留骨骼与 IK 时间轴名称、清除导出的张嘴启动动作、下载固定版本的官方驱动并记录来源哈希。

**渲染器固定版本**：DragonBonesJS 6.0.2 分支的提交 `7b2d9f700d1719db2c5d89a6fa36c85d7f092501` 与 PixiJS 8.9.2；运行库 master 分支会拒绝此 6.0 资源。

**跟随与回正**：通过 `zhuan` 骨骼叠加偏移跟随鼠标，保留 `zhuanshen` 身体及头部约束链；身体位移限制在左右半径 350、上下半径 300 骨架单位的椭圆内，灵敏度 2、眼球偏移 18、0.18 秒平滑；拖拽、动作预览、说话或简洁输入框获得焦点时回正。

### Live2D

Cubism 3/4 开启 `setOpacityFromMotion`，并把动作曲线稳定排列为 Model → Parameter → PartOpacity；切换动作与恢复待机时清空旧动作队列、恢复参数与部件透明度，避免备用手臂部件残留。

### Spine

源码包含独立的官方 Spine WebGL 4.2 驱动与描述符分派，运行 `node scripts/prepare-spine-runtime.mjs [官方包.tgz]` 准备固定校验和的运行库。供应商提供的 Spine 萌妹因贴图组装仍有问题，未加入内置列表。

## 验证

在插件目录运行：

```bash
npm run build
npm test
npm run test:browser     # 真实 Host + 编译后 Client + 空数据目录
npm run test:electron    # 透明区穿透、拖动、重启恢复、隐藏与显示、卸载
```

打包链路在统一工程根目录用 `npm run dist:dev` / `npm run dist:stable` 构建；`scripts/product-v2-smoke.mjs` 以空用户数据检查最终包，验证执行文件哈希、内置资源、角色切换、实际动画与清理。

## 已知限制

- 口型是近似表现，不宣称音素级对齐；情绪格式校验不判断情绪语义质量；
- 音色只用已有克隆 speaker ID，不包含音色训练；
- 供应商提供的 Spine 萌妹素材仍在修整，未进入内置角色库；
- 动作与表情预览需要先开启并保存动画；立绘不执行自动动作；
- 麦克风权限只授予内嵌聊天页，物理麦克风与音色主观质量仍需人工验收。
